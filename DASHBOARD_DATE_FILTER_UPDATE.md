# Dashboard Date Filter Update

The Dashboard header now contains date filters instead of Import/Export controls.

- Default range: Today to Today
- Custom From Date and To Date
- Apply Filter button
- Quick filters: Today, Yesterday, Last 7 Days, Last 30 Days, This Month
- All dashboard analytics use the selected range
- Date basis: Excel `Lead Date`; MongoDB `capturedAt` is used only when Excel Lead Date is missing
